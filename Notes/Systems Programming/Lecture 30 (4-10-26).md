void    add_files(const char *root, List *files) {
    // TODO
    DIR *d = opendir(root);
	if (!d){
		fprintf(stderr, "opendir(%s): %s\n", path, strerror(errno));

	}
	
	for (struct dirent *e = redir(d); e; e = readdir(d)){

### I/O: Overview

- All **input** and **output** is performed on **files:**

1. **Open**
	- Create handle to steam of data
2. **Close**
	- Destroy handle to steam of data
3. **Read**
	- Retrieve chunk from stream of data
4. **Write**
	- Append chunk to stream of data
5. **Seek**
	- Move within stream of data
