### Containters

##### Sequence:
- In C : dynamic arrays, linked list
- In Python: list
	- syntax: \[7,1,4]
##### Fixed:
- In C: Array
- In Python: tuple
	- syntax: (7,1,4)
##### Associative:
- In C: hastables / maps
- In Python: Dictionary
	- syntax: {"duncan" : "south, "siegreid" : "mod"}

##### Membership:
- In C: set
- In Python: set
	- syntax: {"pho", "banh mi"}
